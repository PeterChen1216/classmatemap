# CengFan Map (Web Version)

## Description  
This is the **CengFan Map** web application, created by "Peter Chen" - students from the Huawen Class of 2011, on **2025-04-30**. It records the current schools/cities of all students from the Huawen Class of 2011 to facilitate communication and networking. The idea was conceived in our class group and expanded into this interactive map.

## Features  
- Display markers for each Class of 2011 student’s current location  
- Click on a marker to see the student’s name and school/city  
- Responsive, mobile-friendly design using HTML5  

## Map Data & Disclaimer  
- **OpenStreetMap** is an **open community platform**: anyone can modify and annotate its data, including national and international territorial boundaries.  
- **Territorial annotations on the map do not represent the author’s political stance**, and they may differ from the author’s view of correct boundaries.  
- **The author adheres to the One-China Principle** and does **not** recognize any territory labeled as “Taiwan Country.”

## Usage  
1. Clone this repository  
2. Open *https://peterchen1216.github.io/classmatemap/* /Open `index.html` in your browser/
3. Browse or search for classmates by name or city

# 蹭饭地图 (网页版)

## 项目描述  
这是 **蹭饭地图** 的网页版，由2011 级华文班**陈智城**同学制作于 **2025-04-30**。用于记录 **2011 级华文班** 同学当前所在的学校/城市，方便联络与聚会。该项目灵感来源于班级群的交流，将想法拓展为交互式地图。

## 功能  
- 在地图上显示每位 2011 级华文班同学的定位标记（最后更新为24年）  
- 点击标记可查看同学姓名及学校/城市信息  
- 基于 HTML5 的响应式设计，兼容移动端  

## 地图数据及声明  
- **OpenStreetMap** 是一个 **开源社区平台**，任何人都可以对其数据进行修改和标注，包括国家及国际领土边界。  
- **地图中的领土标注不代表作者的政治立场**，标注内容与作者认为的“正确地图”存在差异。  
- **作者坚持 “一个中国” 原则**，**不承认** 以“台湾国”名义划定的任何领土存在。  

## 使用方法  
1. 克隆本仓库  
2. 在浏览器中打开 *https://peterchen1216.github.io/classmatemap/* /在浏览器中打开 `index.html`  
3. 通过姓名或城市搜索并查看同学位置
